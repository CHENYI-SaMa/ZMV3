测试账号控制台

这是一个严格限定在本地 mock 模式、严格限定在测试账号自身数据范围内的前端测试工具。 所有操作都只会作用于当前测试账号，不会执行全局清空，也不会修改其他用户的数据。

Local Mock Only Test Account Only No Global Reset

如果你在其他标签页同时打开了个人中心、优惠券或订单页面，执行重置后可能需要刷新那些页签才能看到最新状态。

需要先登录测试账号

当前没有有效登录会话。这个控制台只允许当前测试账号本人进入，请先登录测试账号后再使用。

前往登录 返回首页

当前账号无权使用测试控制台

此页面只开放给指定测试账号。为了避免误改其他账号数据，当前账号不会显示任何测试工具。

返回个人中心 切换账号

Test Account Overview

以下信息全部来自共享 mock 数据层的实时读取，不依赖页面内缓存状态。

Quick Test Actions

用于快速构造本地前端联调所需的数据，不会触碰其他用户。

添加 1 条测试订单

创建一条属于当前测试账号的待支付订单，方便验证订单详情、支付页和订单列表流程。

local mock only

添加 1 张测试优惠券

直接发放到当前测试账号名下，方便验证优惠券显示、数量同步和下单使用场景。

test user scoped

恢复默认钱包余额

把当前测试账号的钱包余额恢复到默认 mock 基线，方便重复验证钱包支付流程。

requires confirmation

设置默认测试支付密码

将当前测试账号的钱包支付密码设置为固定测试值，便于快速验证余额支付和密码校验流程。

default: 未设置

重置支付密码为未设置

清空当前测试账号的钱包支付密码，用于验证首次设置流程和未设置拦截逻辑。

requires confirmation

Selective Reset Tools

所有重置都严格限定在当前测试账号自己的 userId 范围内，不会清空全站数据。

重置当前测试账号订单

只清除当前测试账号自己的订单数据，其他用户订单保持不变。

current user only

重置当前测试账号优惠券

只移除当前测试账号名下的优惠券，不影响全局券池和其他用户已领取数据。

current user only

重置当前测试账号钱包

只恢复当前测试账号的钱包数据到默认基线，不会清空其他用户钱包。

current user only

重置当前测试账号支付密码

只清空当前测试账号的钱包支付密码，方便重新走“首次设置支付密码”流程。

current user only

Restore Test Baseline

一键恢复当前测试账号到可重复验证的本地基线状态，不删除账号本身，不影响其他用户。

恢复当前测试账号基线

会重置当前测试账号的订单、优惠券、钱包余额和支付密码，让这个账号回到干净、可重复的 mock 测试状态。

本页不是后台系统，也不是多用户管理台。它只是一个只对测试账号开放的本地 mock 测试工具。
